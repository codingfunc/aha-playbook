# playbook-projects

Practices for non-software projects.

Skills are added one file at a time as practices are decided, not invented up
front. Current skills:

- `market-research` — competitive breakdown of a named niche for a new entrant.

To add one: create `skills/<name>/SKILL.md` with `name` and `description`
frontmatter only, then commit. No manifest change is needed — `skills/` is
auto-discovered.
